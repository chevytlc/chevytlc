# Project Rules

## Commit & Push Safeguards

- **NEVER commit or push without explicit user approval.**
- After making changes, always present a summary of all modified files and key changes.
- Wait for the user to explicitly say "commit", "push", or equivalent before performing either action.
- Treat commit and push as separate approvals — never bundle them.
- Even if the user says "build and ship it", interpret that as "build and show me" — not "commit and push."
- If in doubt, ask. Never assume approval.
